# 大塚事務所格闘録 / Battle

スマートフォン横画面とPCブラウザに対応する、Canvasベースのピクセル格闘ゲームです。

## 画面構成

- `index.html`: タイトル画面
- `select.html`: キャラクター選択、固有技・コマンド確認
- `battle.html`: 対戦画面
- `result.html`: 勝敗表示、再戦・選択・タイトルへの遷移

## JavaScript構成

- `js/fighters.js`: キャラクターデータ、共通状態、対戦開始
- `js/combat.js`: 攻撃判定、ダメージ、ガード、飛び道具、コマンド技
- `js/render.js`: 256×256内部スプライト、描画、ゲームループ
- `js/input.js`: キーボード、仮想スティック、4ボタン操作
- `js/select.js`: キャラクター選択画面
- `js/battle.js`: 対戦画面の初期化
- `js/result.js`: リザルト画面

画面間の選択キャラクター・勝敗情報は `sessionStorage` で受け渡します。

## 基本操作

| 操作 | 内容 |
|---|---|
| ← / → または A / D | 移動 |
| ↑ または W | ジャンプ |
| ↓ | しゃがみ |
| J / タッチ「パンチ」 | パンチ |
| K / タッチ「キック」 | キック |
| P / タッチ「必殺」 | キャラクター固有必殺技 |
| L / タッチ「セービング」 | セービング |
| 相手と反対方向 | ガード |

## 攻撃属性

- 空中攻撃: 上段
- 立ち攻撃: 中段
- しゃがみ攻撃: 下段
- パンチ: 弱攻撃 / キック: 中攻撃
- 相手方向を入力しながらパンチ・キック: 強攻撃へ派生
- 攻撃の硬直後半に次の攻撃を入力すると連係。連係中は必殺技にもつながる
- キャラクターごとに固有の連係ルート、モーション特性、攻撃後硬直を設定
- 上段攻撃はしゃがみで回避。中段は立ちガード、下段はしゃがみガードで防御。

## コマンド技

- ↓→ + パンチ: 連環弾
- →↓→ + キック: 突進奥義
- ←← + パンチ: 後退反撃
- 必殺ボタン: キャラクター固有技
